# Anexo B. Objetivos de aprendizagem e o que a síntese tem de mostrar

Quando o estudante fornece os objetivos do programa ou do guia de estudo, os verbos desses objetivos dizem que tipo de compreensão vai ser avaliada. A síntese não responde a perguntas, mas deve conter a matéria de que o estudante precisa para cumprir cada objetivo. Este quadro traduz cada verbo nesse conteúdo.

| Verbo no objetivo | O que a síntese tem de tornar claro |
| --- | --- |
| Identificar, indicar, referir | Os elementos pertinentes, bem delimitados e com o nome correto. |
| Definir | O significado do conceito no autor, o seu âmbito e o que o distingue dos conceitos próximos. |
| Caracterizar | Os traços distintivos de um fenómeno, período ou instituição, e como se articulam entre si. |
| Descrever | O desenrolar de um processo ou a forma de uma realidade, com a ordem e a escala certas. |
| Contextualizar | As circunstâncias de tempo, espaço, sociedade e ideias que tornam o tema compreensível. |
| Explicar | O como e o porquê, com as relações entre fatores tal como os autores as apresentam. |
| Relacionar | O tipo de ligação entre os elementos (causa, condição, consequência, contraste, influência). |
| Comparar, distinguir | Critérios comuns de comparação e as diferenças e semelhanças segundo esses critérios. |
| Analisar | Os elementos de um fenómeno ou documento, as relações entre eles e os seus limites. |
| Interpretar | O sentido proposto pelos autores e a base em que o apoiam. |
| Problematizar, discutir | As questões em aberto, as posições dos autores e o que está em jogo entre elas. |
| Avaliar | Os critérios usados pelos autores para formular um juízo e as razões que apresentam. |

### Objetivos combinados ou vagos

Se o objetivo combinar verbos ("identificar e distinguir"), a síntese cobre as duas operações. Se for vago ("abordar", "conhecer"), escolher o eixo a partir do conteúdo das fontes e dizê-lo na contextualização.

Sem objetivos fornecidos, o eixo da síntese define-se pelas próprias fontes (qual é o problema que tratam e qual é a resposta que dão), e os objetivos da contextualização formulam-se a partir dele, com os verbos deste quadro.
